# Sai: portfolio

A dark, quiet portfolio built around four things I love: racing, games, forests and anime.

**Live site:** https://sai-glit.github.io

## What's inside

- A start-light intro that ends with a single slash, then the page fades in from the fog
- A headlight effect that follows the cursor, and fireflies drifting across the page
- My projects, with the Deforestation-Risk-Detector featured
- A lap-progress bar and sector labels that follow the scroll, like a race weekend

## Built with

Plain HTML, CSS and JavaScript in a single `index.html`, with no frameworks or build step. Fonts are Chakra Petch, Newsreader and Shippori Mincho from Google Fonts. The animations switch off for visitors who prefer reduced motion.

## Run it locally

Download `index.html` and open it in any browser.
